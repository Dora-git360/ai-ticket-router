# AI Ticket Router

## Overview

This project is an AI-powered ticket routing workflow built using n8n and Google Gemini AI.

It analyzes incoming support tickets and automatically routes them to the appropriate team based on the ticket category and business rules.

## Features

- AI-powered ticket routing
- Automated workflow with n8n
- Google Gemini AI integration
- Business rule-based routing
- JSON API support

## Workflow

Webhook
↓
Edit Fields
↓
Google Gemini AI
↓
Route Ticket
↓
Return Response

## Technologies Used

- n8n
- Google Gemini AI
- REST API
- JSON
